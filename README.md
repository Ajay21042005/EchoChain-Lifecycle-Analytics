# EchoChain - Lifecycle Analytics

## Internship Project

## Project Title

Circular Economy & Secondary Market Lifecycle Analytics

## About the Project

This project is about analyzing used electronic products sold on different online marketplaces like OLX and eBay. The main aim is to understand product prices, popular brands, and resale trends by cleaning the data, analyzing it, and creating dashboards.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Power BI
- Git & GitHub
- VS Code
- Jupyter Notebook

## Datasets Used

- OLX Dataset
- eBay Dataset
- Used Devices Dataset

The datasets include products such as:
- Mobile Phones
- Laptops
- Tablets
- Smartwatches
- Cameras
- Headphones
- Gaming Consoles

During the project, I faced some issues while cleaning the datasets because of missing values, different data formats, and inconsistent columns. I also had some problems while importing datasets and creating visualizations in Power BI. I solved these issues by checking the data carefully and fixing them step by step.
